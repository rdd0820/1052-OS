# 删除工作区与流程编排

## 原则
- 按“单项功能 → 全仓引用审计 → 明确保留/迁移依赖 → 删除 → 定向测试”的顺序推进，不做关键词式批量删除。
- 保留定时任务、日历、执行记录中的 scheduled-task 记录、Agent 通用终端、filesystem 工具、Agent workspace、知识/技能、外部通道及其运行时依赖。
- 删除代码不自动删除 `DATA_DIR` 下的用户数据；先保留并记录可能的归档目录，不触碰真实仓库、数据库或远程服务器。

## 实施步骤
1. **建立依赖基线**：逐个审计 Repository、SQL 子系统（数据源/查询/SQL 文件/变量/SSH/Shell）、Orchestration 的导入者、路由/API、Agent 工具注册与 pack、运行时安全策略、前端路由/导航/共享视图、契约、脚本、测试、包依赖及数据文件格式。将每项依赖分成“随功能移除”“改造后保留”“明确保留”，先运行相关测试作为基线。
2. **移除仓库功能**：清理 `frontend/src/pages/workspace/repositories.tsx`、repository API/schema/routes/service/types 与 Agent repository tools；更新工具注册、pack、P0 路由描述和测试。检查 `repository` 在 memory scope、websearch 技能来源中的独立语义，保留非仓库浏览用途；保留通用 filesystem/terminal/Claude Code 工具。
3. **移除流程编排功能**：清理 `frontend/src/features/automations/AutomationFlowView.tsx`、编排页面、API、契约及后端 orchestration 模块和 Agent 工具；在 `AutomationViews.tsx` 仅移除流程日志查询/面板，保留日历、定时任务及普通任务运行记录。同步工具 registry/pack、安全策略、runtime 串行名单与测试。
4. **移除 SQL/工作区剩余能力**：在确认编排已拆除后，清理 SQL 工作台、数据源、SQL 文件、变量、SSH 服务器、Shell 文件的 UI/API/schema/routes/service/client/runner/types、Agent SQL tools、依赖和测试。逐一检查 SQL 服务所有调用方及 `mysql2`、`ssh2`、`@codemirror/lang-sql` 等依赖；保留仍由 Intel Center、Skills、研究会话等用途依赖的 Python、`unzipper`、`better-sqlite3` 等通用依赖。
5. **收口路由与残留引用**：更新 `frontend/src/app/App.tsx`、`frontend/src/app/navigation.tsx`，使旧路由不再注册且 `/workspace` 不重定向到已删除页面；清理 `frontend/src/data/api.ts`、`frontend/src/contracts/schemas.ts`、相关功能目录。更新 RunsView 和 `frontend/scripts/`、E2E、smoke/README 截图脚本，避免访问已移除路由/API。审计旧数据目录（repository config、SQL 配置/文件、编排定义/日志），只决定保留/备份策略，不自动删除用户数据。
6. **验证保留能力与删除边界**：运行前后端构建及相关单测、全量测试和前端 E2E/smoke；增加退役路由/API返回 404、退役 Agent 工具不再注册/调用、保留的 schedule/terminal/filesystem 工具仍可用等测试。再次全仓搜索旧页面、API、工具名和服务导入；逐个解释剩余命中，并验证日历、定时任务、任务运行记录、知识、通道及 Intel Center 不受影响。

## 关键依赖边界
- `backend/src/modules/orchestration/orchestration.service.ts` 直接使用 SQL/SSH/Shell 服务；先拆编排，再删 SQL 服务。
- `frontend/src/features/automations/AutomationViews.tsx` 同时包含定时任务视图与编排执行日志；只删后者。
- 定时任务由 `backend/src/modules/calendar/calendar.schedule.service.ts` 调用独立 `terminal.service.ts`；保留其 terminal 目标及 `schedule_*` Agent 工具。
- `backend/src/modules/agent/agent.workspace.service.ts`、通用 filesystem/terminal 工具、Intel Center Python 路径都不属于待删模块。
- 用户数据根目录在当前 workspace 外；实施时不自动清理数据、远端资源或旧聊天记录。
